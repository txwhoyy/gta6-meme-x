# GTA 6 Meme on X — "Still Waiting Since 2013"

An original GTA 6 waiting meme: a skeleton gamer slumped in his chair in front of the monitor, the wall calendars behind him crossed out year after year from 2013 all the way to 2026, and the make.fun ghost glowing on the screen — AI agents have started building games of their own, and GTA 6 still isn't out.

![The meme](meme.png)

The meme is the entry, and it lives on X, posted publicly by the entrant:

https://x.com/spidolhitam11/status/2123541969754587556

This repository names that post in [POST.json](POST.json). The small program in [main.ts](main.ts) validates the post address in POST.json and hands the file to the grader by copying it into the output directory.

## Run it

```sh
mkdir -p out && MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out node main.ts
```
